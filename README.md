# 📝 Floating Task Manager Desktop App

A simple floating desktop task manager that stays on top of other windows, helping you manage tasks quickly and stay organized.

---

## 🚀 Features

- Floating always-on-top window
- Add, edit, and delete tasks
- Mark tasks as completed
- Clean and minimal interface
- Lightweight and easy to use

---

## ⚙️ Run Locally

```bash
git clone https://github.com/your-username/floating-task-manager.git
cd floating-task-manager
npm install
npm start
